# InvoiceForge - Free Invoice Generator

Create professional invoices in seconds. A free, client-side invoice generator for freelancers and small businesses. No signup required, no data stored.

## Live Demo

[invoice-generator-gold-eight.vercel.app](https://invoice-generator-gold-eight.vercel.app)

## Features

- Professional invoice form with sender and client details
- Live preview panel showing the invoice as it will appear when printed
- Add/remove line items with auto-calculated amounts
- Tax rate input with automatic subtotal, tax, and total calculation
- Multi-currency support (USD, EUR, GBP, MXN, CAD)
- Download as PDF via browser print (no external dependencies)
- Responsive design: side-by-side on desktop, stacked on mobile
- Clean, minimal UI with Lucide React icons

## Tech Stack

- **Framework:** Next.js 16 (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS v4
- **Icons:** Lucide React
- **Deploy:** Vercel

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
